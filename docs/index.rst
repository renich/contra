Operational Primitives
======================

* **Zero Fluff**: Direct, metric-driven communication. No hollow marketing jargon.
* **Productized Scopes**: Fixed deliverables with unambiguous "Out of Scope" boundaries over unconstrained hourly billing.
* **Empirical Verification**: Every proposal, milestone deliverable, and portfolio piece must be backed by verifiable tests, code repositories, or measurable outcomes.
* **Single Source of Truth**: All operational copy, case studies, and proposals are authored in version-controlled reStructuredText (``.rst``) files in this repository.
